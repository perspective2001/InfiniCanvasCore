## Verification chain — do not collapse stages
1. **Source modified** = SHA and diff known, **not** compiled.
2. **Mac build** = Xcode 27 + iOS 26 simulator compile on latest head SHA; any failed test or test skipped is still a blocker.
3. **Native visual** = rendered iPad pixels and recording from **that same** SHA captured, opened and critiqued, including motion/gesture states; static math previews are not sufficient.
4. **Physical device acceptance** = iPad Pro M5 + Pencil Pro, exact candidate IPA SHA, reported user approval for all P0 interactions, app persists after relaunch.
5. **Release** = after all above, reviewed merge + patch tag with no existing app/sandbox migration; then *original AppRelay* fetches the matching IPA; re-sign over correct installed identity with Sideloadly. Retain previous rollback source + safe complete backup.
